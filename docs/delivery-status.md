## 未完成与风险

- ETF 历史买入只有金额时，尚未实现按可追溯成交时点市场价格推算；当前
  实时行情链路只负责当前估值。
- JSON 导出存在协议阻塞：当前导入一次只接受一个账户，交易协议只接受
  `BUY`/`SELL`，无法无损回导多账户以及校准、取消、冲正历史。
- 已确认交易更正尚缺后端历史重建协议与客户端闭环。
- 尚未用生产 Compose 完成 MySQL、Redis、SMTP 的端到端启动与故障验证。
- 尚未选择云平台、域名和正式邮件服务，也未完成 HTTPS、备份和日志告警。
- 免费公开行情没有 SLA，商用前必须重新确认授权与稳定性。
